# DeclarationAudit — онлайн-база знаний

Источник обновлений для расширения Chrome **DeclarationAudit** (проверка деклараций о соответствии ЕАЭС).

- `manifest.json` — версия базы и контрольные суммы файлов;
- `rules.json` — правила проверки: обязательные показатели и нормы по ТР ТС 015/2011, методы и необходимое оборудование, справочник пестицидов, перечень нормативной базы;
- `npa/` — тексты нормативных актов (ТР ТС/ЕАЭС, ПП РФ № 936, 184-ФЗ, 412-ФЗ, решения ЕЭК).

Расширение проверяет обновления раз в 6 часов и сверяет SHA-256 каждого файла. Тексты НПА приведены для справки; официальные редакции — на официальных порталах.

Текущая версия: **2026.10.30-1**.
